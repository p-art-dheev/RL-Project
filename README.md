# PACE: carbon- and SLA-aware edge–cloud scheduling with deep RL

A student RL project extending **MERSEM** (arXiv:2605.13489, 2026), using the online-RL lineage of
**DeepRM** (HotNets 2016) and **DeepRM2** (arXiv:1806.08122).

- Design proposal, paper analysis, RL formulation, AWS testbed plan, experiments and demo script:
  [`docs/PROPOSAL.md`](docs/PROPOSAL.md)

Status: design phase; implementation has not started yet.
