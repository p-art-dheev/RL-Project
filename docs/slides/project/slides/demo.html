Camera in, detections out

Every webcam frame becomes an alert job; HOG pedestrian detection runs on whichever node PACE picks, and the count appears live

Run order is in docs/RUNBOOK.md section 5. The carbon clock is time-compressed (1 grid hour per minute) so hourly changes are visible in a 10-minute demo; say this out loud. Backup if the network fails: the fully local mode, and say that delays are not real in that mode.
