RL formulation

One decision each time a task becomes ready

State

Per node: tier, speed for this task type, queue wait, transfer time from parents, grid intensity now and +1 h / +3 h, finish-vs-deadline. Per task: class, work, slack, critical path, remaining job work, w.

Action

Pick a node, or DEFER a batch task 15 min. Masks remove dead nodes, nodes without memory, and foreign regions for privacy-restricted feeds.

Reward

r = −[(1−w) · task carbon per unit work, relative to Mumbai + w · (½ task sub-deadline penalty + ½ job deadline penalty)]

Learning

Behaviour cloning of the best heuristic (DeepRM2 idea), then PPO over randomised topologies, loads, noise and failures; w ~ U[0,1] per episode. ~60k parameters, CPU only.

Lesson worth telling: our first reward split each job's deadline penalty across its tasks. A single task decision then almost never changed the outcome of a 25-task job, so the deadline signal was noise and the policy ignored w. Deadline decomposition (each task gets a sub-deadline = job deadline minus its remaining critical path) made the signal attributable to the decision.
